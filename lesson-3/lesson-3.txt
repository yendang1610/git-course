Bài tập 1:

git commit --amend: thay đổi commit cuối cùng
git commit --amend -m "message": thay đổi commit message
git restore --staged <file>: Thay đổi commit message, đưa từ vùng staging về working directory
git reset HEAD~1: Thay đổi commit message: đưa từ vùng repository về working directory (uncommit)
