Git init: Khởi tạo thư mục được quản lý bởi Git
Git add <file_name>: add 1 file từ working directory sang staging area
Git add . : add toàn bộ file vào khu vực chờ commit (Vùng staging)
Git commit -m "<commit message>": Tạo ra 1 phiên bản dựa vào các file đã được thêm ở vùng staging vào Repository với thông điệp là "message"
